# 场景、提示词与审核规则

在规划章节场景、组装提示词、审核图片或分析重试原因时读取。

## 场景计划最低合同

每个正式章节场景必须包含：

- `environment`：原文支持的时间、地点、天气、建筑或空间状态；
- `keyAction`：画面这一刻正在发生的剧情事件；
- `subjectInteraction`：人物之间或人物与事件/环境之间的反应与空间关系；
- `composition`：16:9 下的景别、视线重心以及前中后景；
- `evidenceSegmentIds`：支持该场景的原文章节片段；
- `insertAfterSegmentId`：属于证据片段的正文插入锚点。

缺少前四项中的任意一项，不得进入生图。

## 推荐提示词骨架

```text
为中文小说第{chapterNo}章生成一张横向叙事情景插图。

小说类型与时代：{genre_and_era}
全书视觉风格：{visual_bible}
场景环境：{environment}
关键事件：{key_action}
主体互动：{subject_interaction}
人物外貌：{approved_stable_traits}
本章动态状态：{dynamic_traits}
画面构图：16:9，2560×1440，{composition}，环境必须承担叙事作用。

只呈现本章证据明确支持的内容；保持人物、服装时代、空间与事件一致。
这是一张小说情景插画，不是人物写真、角色海报或静态肖像。
```

参考图提示必须明确：只继承人物五官、发型、年龄感、体型和标志性特征，不继承参考图的背景、姿势、灯光与镜头。

## 必备负面约束

```text
明显鲜血，血腥特写，断肢，内脏，尸块，色情，违法内容，水印，
logo，乱码文字，对话气泡，现代物件（除非原文明示），畸形肢体，
多余手指，凭空新增人物，未来剧情剧透，个人写真，人物写真，角色海报，
证件照，影棚背景，纯色背景，空白背景，单人静态站姿，
只画人物而没有剧情环境，沿用参考图的背景或姿势
```

若输入包含明显血腥表述，改写为“激烈但克制的战斗氛围”，保留冲突和动作感，不保留血腥细节。

## 硬审核阈值

| 维度 | 阈值 |
|---|---:|
| 剧情一致性 `narrativeMatch` | ≥ 0.80 |
| 场景叙事性 `sceneStorytelling` | ≥ 0.85 |
| 人物一致性 `characterConsistency` | ≥ 0.85 |
| 画面质量 `imageQuality` | ≥ 0.75 |
| 内容安全 `safetyPassed` | 必须通过 |

所有条件同时满足才可自动展示。写真、角色海报、静态站姿或缺少叙事环境的图片，场景叙事性最高只能记为 `0.40`。

## 重试

- 首次失败后最多自动重试三次，总调用最多四次。
- 每次根据上一轮审核原因局部修正提示词，不改变原文事件。
- 只重试失败章节，不重新生成已通过章节。
- 不因画面“更酷”而接受剧情错误、人物漂移或未来剧透。
- 四次均失败后停止，并返回每次审核原因。

## 发布前检查

- 图片确实来自要求的模型和版本；
- 尺寸、比例和水印配置正确；
- 临时图片已成功转存永久对象存储；
- 审核报告与图片版本绑定；
- 插入锚点仍存在且文本哈希一致；
- 新版本通过前没有替换当前正式图；
- 已保留旧版本和重新生成原因。
